# JavaScript-pusslet

Ett drag-and-drop-spel för att träna JavaScript i kursen JavaScript 1 (FEND26). Eleven pusslar ihop kodbitar till ett fungerande program och ser sedan vad koden skriver ut i konsolen. Spelet tränar funktioner, `if`/`else`, for-loopar, arrow functions och array-metoder, både på vanliga arrayer och på arrayer med objekt.

**Spela:** https://zairaxx.github.io/javascript-pusslet/

## Nivåer
1. Funktioner
2. if / else
3. for-loopar
4. Arrow functions
5. Array-metoder
6. Arrayer med objekt
7. Slutboss: Spellista

Allt ligger i `index.html` (ingen build behövs). Framsteg sparas i webbläsarens localStorage.
